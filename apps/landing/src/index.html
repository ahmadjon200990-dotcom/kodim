Ko'p beriladigan savollar

O'quvchi telefonda ekranni suratga olsa-chi?

Hech qanday dastur telefon kamerasini to'xtata olmaydi — bu o'qituvchi nazorati bilan qoplanadi. Ekran rasmi olish tugmalari esa bloklanadi va qayd etiladi.

Internet uzilsa, ish yo'qolmaydimi?

Yo'q. Ish kompyuterda saqlanadi va har 5 soniyada serverga yuboriladi. Qayta ulanganda davom etadi, vaqt esa server bo'yicha hisoblanadi.

npm, Vite, React, Python ishlaydimi?

Ha. O'qituvchi ruxsat bergan buyruqlar (npm install, npm run dev, node, python …) ishlaydi; boshqa buyruqlar va zanjirlash bloklanadi.

Figma dizayn uchun o'quvchiga akkaunt kerakmi?

Kerak emas. O'qituvchining Figma tokeni bilan server dizaynni oldindan yuklaydi; o'quvchi o'lcham, rang va shriftlarni ilova ichida ko'radi.

Internetsiz sinfda ishlatsa bo'ladimi?

Ha. Serverni o'qituvchi kompyuterida ishga tushirib, o'quvchi ilovasida sozlama orqali lokal tarmoq manzilini (masalan 192.168.1.10:8080) kiritish mumkin.

O'qituvchi qanday ro'yxatdan o'tadi?

O'qituvchi paneliga Google akkaunti bilan kiradi — birinchi kirishda akkaunt avtomatik yaratiladi.
